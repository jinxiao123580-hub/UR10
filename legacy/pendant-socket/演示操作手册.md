# UR10 机械臂 × ROS 通信 演示操作手册

> 环境：Ubuntu 22.04 · ROS2 Humble · UR10 + CB3 控制柜（固件 3.15.8）
> 机械臂 IP：192.168.1.3 · 电脑主板网口：192.168.1.10
> 全部脚本：`~/ur_learn/scripts/` · ROS 包：`~/ros2_ws/src/ur_link/`（已编译）

---

## 0. 演示前检查清单（3 分钟）

```bash
# ① 网络：主板网口固定 IP + 绕过代理
ip -br addr show enp0s31f6          # 应有 192.168.1.10/24
ip route get 192.168.1.3            # 应显示 via enp0s31f6（不能是 singbox_tun）
ping -c 2 192.168.1.3               # 应通

# ② 若上面不对，跑一键配置（需要 sudo）
sudo bash ~/ur_learn/scripts/network_setup.sh
```

机械臂侧：控制柜开机 ≥1 分钟、示教器正常、机器人已上电、刹车已松、**没有程序在运行**、特征=Base。

## 3. 步骤二：读关节状态（机器人 → ROS）

**终端 A（开状态节点，保持运行）：**
```bash
source /opt/ros/humble/setup.bash && source ~/ros2_ws/install/setup.bash
ros2 run ur_link ur_state_node --ros-args -p robot_ip:=192.168.1.3
```

**终端 B（看数据）：**
```bash
source /opt/ros/humble/setup.bash && source ~/ros2_ws/install/setup.bash
ros2 topic echo /joint_states
```
预期：每 100ms 一条，6 个关节角度 `shoulder_pan_joint ... wrist_3_joint`。
还可看：`/ur_link/robot_mode`、`/ur_link/is_program_running`、`/ur_link/speed_fraction`。

---

## 4. 步骤三：画小圆（ROS → 机器人，核心演示）

**终端 C（开指令节点，保持运行）：**
```bash
source /opt/ros/humble/setup.bash && source ~/ros2_ws/install/setup.bash
ros2 run ur_link ur_command_node --ros-args -p robot_ip:=192.168.1.3
```

**终端 D（发画圆命令）：**
```bash
source /opt/ros/humble/setup.bash && source ~/ros2_ws/install/setup.bash
python3 ~/ur_learn/scripts/ur_circle.py 0.02
```
- 脚本自动读当前 TCP 位姿 → 生成**字面量圆心**的画圆 URScript → 发给机器人；
- 机械臂在**水平面画半径 20mm 的圆**，一直画（while True）；
- 同时终端 B 的 `/joint_states` 角度持续变化 → 直观看到 ROS 控制生效。

**停止：**
```bash
ros2 service call /ur_link/dashboard/stop std_srvs/srv/Trigger
```
或按急停。

## 7. 附录 A：关键坑（演示若失败对照查）

| 现象 | 原因 | 解决 |
|---|---|---|
| 端口"连上但零数据"、ping 不通 | sing-box/Clash 代理劫持局域网流量 | `sudo bash network_setup.sh` |
| 脚本发出去机械臂不动 | ①字符串用了单引号 ②没 def 包裹 ③发完秒关 socket | 脚本用双引号 + def 包裹 + 长连接（本工具已处理） |
| 脚本一调 `get_actual_*` 就中止 | 这台机器客户端接口禁内省函数 | 用"电脑端读位姿→字面量"方案（本工具已处理） |
| `waiting for service` | command_node 没开 | 先 `ros2 run ur_link ur_command_node` |

## 9. 步骤六：抓取-放置演示（可选扩展）

**原理**：手动把机器人移到两个目标点各记录一次 → 程序自动完成"下降→闭合→抬起→平移→下降→张开→抬起"。

**① 记录点位**（终端，先手动把机器人移到抓取点）：
```bash
python3 ~/ur_learn/scripts/ur_capture_pose.py pick    # 移到抓取点后运行
# 手动把机器人移到放置点
python3 ~/ur_learn/scripts/ur_capture_pose.py place   # 移到放置点后运行
```
（点位存到 `~/ur_learn/poses.json`，可随时重录）

**② 执行抓取-放置——两条路**（⚠️ 重要：Robotiq 的 `rq_*` 函数**只能在示教器程序里用**，注入式脚本会中止，已验证）

**路线 A：ROS 注入（只做机械臂运动，夹爪另控/跳过）**（command_node 开着）：
```bash
python3 ~/ur_learn/scripts/ur_pick_place.py pick place 0.05 --forever   # 一直循环(默认跳过夹爪)
python3 ~/ur_learn/scripts/ur_pick_place.py pick place 0.05             # 单次
```
- `0.05` = 安全高度（米）；
- 默认**跳过夹爪**（`rq_*` 注入不可用）；若强行带夹爪会中止——别用 `--gripper`。

**路线 B：示教器跑完整抓放（带夹爪）**：
1. 打开文件 `~/ur_learn/demo/pendant_pick_place.urscript`，复制全部内容；
2. 示教器：新建程序 → 插入 **"脚本(Script)"节点** → 粘贴 → 保存 → 播放；
3. 机械臂完成：激活夹爪→降→闭→抬→平移→降→张→抬（rq_* 在示教器里有效）。
4. 想循环：把动作包进 `while True:` 或用 URCap 的循环。</parameter>



**停止**：`ros2 service call /ur_link/dashboard/stop std_srvs/srv/Trigger` 或急停。

## 10. 电脑远程控制 Robotiq 夹爪（socket 中继）

原理：`rq_*` 只能在示教器环境用 → 示教器跑一个"夹爪服务器"小程序，
电脑通过 TCP 向它发命令，实现**从电脑控制夹爪开合**。

**① 电脑开服务器**（终端）：
```bash
python3 ~/ur_learn/scripts/ur_gripper_server.py 30010
```
显示"等待机器人连入"。

**② 示教器运行夹爪服务器程序**：新建程序 → 插"脚本(Script)"节点 →
粘贴 `~/ur_learn/demo/pendant_gripper_server.urscript` 内容 → 播放。
机器人会连上电脑，服务器终端显示"机器人已连入"。

**③ 电脑输入命令控制夹爪**：
```
open    # 张开 (rq_move_to 0)
close   # 闭合 (rq_move_to 255)
quit    # 断开
```
夹爪响应后服务器会打印机器人的回执（opened/closed）。

**说明**：夹爪动作由示教器程序执行（rq_* 有效），但**触发权在电脑**。

## 11. 循环抓取-放置 + 夹爪 + 电脑控制（推荐演示方案）

把电脑可控夹爪整合进循环抓放：示教器无限循环抓放，夹爪每轮开合，电脑可看进度/发 stop。

**程序文件**：`~/ur_learn/demo/pendant_pick_place_loop.urscript`（已含实际 pick/place 点位）

**① 电脑开服务器**（终端）：
```bash
python3 ~/ur_learn/scripts/ur_gripper_server.py 30010
```

**② 示教器**：新建程序 → 插"脚本(Script)"节点 → 粘贴 `pendant_pick_place_loop.urscript` 内容 → 保存 → **播放**。
程序会自动：连电脑 → 激活夹爪 → **无限循环**（抓取点上方→下降→闭合→抬起→平移到放置点上方→下降→张开→抬起）。

**③ 电脑终端看到**：每轮 `[机器人] gripped` / `[机器人] released`；输入 `stop` 可停止循环。

**停止**：电脑发 `stop`，或示教器停止，或急停。

## 12. ROS 式按需控制（通用执行器 + ROS 桥）—— 推荐最终形态

**效果**：像订阅 ROS 话题一样，电脑**随时**发抓/松/移动，机器人立刻执行。点位不写死，完全通用，以后做任何任务都用这一套。

**① 示教器**：粘贴 `~/ur_learn/demo/pendant_command_executor.urscript` → 保存 → 播放（跑一次，之后一直待命）。

**② 电脑起 ROS 桥**：
```bash
source /opt/ros/humble/setup.bash && source ~/ros2_ws/install/setup.bash
ros2 run ur_link ur_gripper_cmd --ros-args -p port:=30010
```
显示"执行器已连入"。

**③ 像 ROS 一样控制**（任意时刻、任意终端）：
```bash
# 夹爪：255=闭合, 0=张开
ros2 topic pub --once /ur_cmd/gripper std_msgs/Int32 "data: 255"
ros2 topic pub --once /ur_cmd/gripper std_msgs/Int32 "data: 0"

# 机械臂：移到任意位姿 [x,y,z,rx,ry,rz]
ros2 topic pub --once /ur_cmd/move std_msgs/Float64MultiArray "data: [0.6,-0.2,0.3,1.9,-2.3,0]"

# 退出执行器
ros2 topic pub --once /ur_cmd/stop std_msgs/Int32 "data: 1"   # 或直接 Ctrl-C 电脑/示教器停止
```
（也可用 `python3 ~/ur_learn/scripts/ur_gripper_server.py 30010` 代替 ROS 桥，终端输 grip/release/move）

**优点**：换点位/换任务不改示教器脚本；抓放/移动/夹爪全部按需、可随时穿插；以后接 MoveIt 规划器也走这条 socket 通道即可。
