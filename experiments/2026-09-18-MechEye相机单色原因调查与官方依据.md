# Mech-Eye 相机只能得到单色图像的官方依据（汇报材料）

调查日期：2026-09-18 · 设备：`Mech-Eye PRO XS`（`192.168.1.33`，SN `RAM35238A3020004`）

## 结论

本机 2D 图像只能得到单色，**原因是相机硬件的 2D 图像传感器本身为单色（Monochrome）**，
不是参数配置错误，也不是链路故障。官方规格表对该型号明确标注
`2D image color: Monochrome`，且该系列不存在任何彩色物料编码的版本。

因此不存在“打开彩色”的软件开关；需要真彩色只能更换彩色型号或外挂 RGB 相机。

## 二、什么样的物料编码代表单色

从证据 3 的官方型号表解析出的完整对照（`M` = Monochrome，`C` = Color）：

| 系列 | 单色编码（尾部 `M`） | 彩色编码（尾部 `C`） |
|---|---|---|
| NANO-GL | `NANO-V4D350M`、`NANO-V4D550M` | `NANO-V4D350C`、`NANO-V4D550C` |
| PRO S-GL | `PRO S-V4D500M`、`PRO S-V4D700M`、`PRO S-V4D1000M` | `PRO S-V4D500C`、`PRO S-V4D700C`、`PRO S-V4D1000C` |
| PRO M-GL | `PRO M-V4D1200M`、`PRO M-V4D2000M` | `PRO M-V4D1200C`、`PRO M-V4D2000C` |
| NANO ULTRA-GL | `NANO ULTRA-350M`、`NANO ULTRA-700M` | 无彩色版本 |
| UHP-140-GL | `UHP-140-MP30D300M` | 无彩色版本 |
| Laser L Enhanced | `Laser L Enhanced-12MP-1500M`、`-3000M` | 无彩色版本 |
| LSR S / L / XL-GL | 无单色版本 | `LSR S-V4D800A`、`LSR L-V4D1500A`、`LSR XL-V5D2500A` 等 |
| DEEP-GL | 无单色版本 | `DEEP-V4D3000A` |

**判定规则**：物料编码末位字母即 2D 图像色彩 ——
`M` = Monochrome（单色）、`C` = Color（彩色）。
LSR / DEEP 系列只有彩色版本，末位使用 `A`。

### 本机的编号情况

GVCP 发现读到的是**型号名** `Mech-Eye PRO XS`，而不是物料编码。要点：

- **PRO XS 从未出现在上述“相机型号表”中**（2.3.1 与 2.5.0 两版均无该行），
  即官方没有为 PRO XS 提供任何彩色物料编码。
- PRO XS 只有独立规格页，该页明确写 `2D image color: Monochrome`。
- 结论：**PRO XS 系列不存在彩色版本**，与“型号表里凡有彩色版本的系列都会同时列出 `M`/`C` 两个编码”这一规律一致。

## 三、灰色三通道图像是怎么产生的

官方 SDK 文档（证据 4）原文：

> `Color2DImage getColorImage() const` — … If the color type is `Frame2DColorType.Monochrome`,
> this method converts the Gray values to ColorBGR values according to the following equation:
> **Blue = Gray, Green = Gray, Red = Gray**.
>
> `GrayScale2DImage getGrayScaleImage() const` — … If the color type is Monochrome,
> this method gets the original data.

完整链路：

```
PRO XS 单色传感器（蓝光 459 nm + 窄带滤光片）
  │
  ├─ SDK: camera.capture2D(frame)        → Frame2D，colorType() = Monochrome
  ├─ frame.getColorImage()               → SDK 按 Blue = Gray, Green = Gray, Red = Gray 复制
  ├─ 官方 ROS 2 接口 publishColorMap()
  │       cv::Mat(h, w, CV_8UC3, data)   → 按 3 通道解释
  │       encoding = BGR8                → 标记为 bgr8
  │       frame_id = mechmind_camera/color_map
  └─ /mechmind/color_image → 显示为灰度图
```

### 本机实测数据与公式吻合

`outputs/camera/capture-validation-20260914-154850.json`：

```json
"channel_mean": [57.797, 57.797, 57.797],
"channel_std":  [59.234, 59.234, 59.234],
"mean_channel_spread": 0.0,
"channels_identical_fraction": 1.0
```

B=G=R 且**逐像素**相同、三通道统计量完全相等 —— 即只有一个灰度平面被复制了三份。
若 SDK 是把单色缓冲区**重新解释**为三通道（而非复制），三通道将互不相同；
因此实测结果与官方文档所述 `getColorImage()` 的显式复制行为逐字吻合。

### 话题名为什么会误导

官方 ROS 接口迁移指南记载：SDK 2.0.2 时代该采集服务名为 `CaptureColorMap`，
2.3.4 起改名 `CaptureColorImage`，但**话题名 `/mechmind/color_image` 与
frame_id `mechmind_camera/color_map` 沿用了 `color` 字样**。
话题名含 `color` 不代表数据是彩色的。

## 四、查询编号的最简代码

### 方式 A · 纯 Python，零依赖，无需安装 SDK（最简，本机已验证可运行）

```python
import socket, re
s = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)
s.setsockopt(socket.SOL_SOCKET, socket.SO_BROADCAST, 1); s.settimeout(6)
pkt = bytes([0x42,0x11,0,2,0,0,0,1])              # GVCP DISCOVERY_CMD
for dst in ("255.255.255.255", "192.168.1.255"):  # 两个广播地址都要发
    s.sendto(pkt, (dst, 3956))
while True:
    try: data, addr = s.recvfrom(2048)
    except socket.timeout: break
    print(addr[0], "->", [x.decode(errors="replace").strip()
                          for x in re.findall(rb"[ -~]{4,}", data)])
```

本机实际输出（返回顺序固定为 厂商 / 型号 / 版本 / 厂商 / 序列号）：

```
192.168.1.33 -> ['Mech-Mind Robotics', 'Mech-Eye PRO XS', '2.5.0', 'Mech-Mind Robotics', 'RAM35238A3020004']
```

> 注意：只向 `255.255.255.255` 发送时本机收不到应答，必须同时发子网广播 `192.168.1.255`。

### 方式 B · 判断“这台相机是不是单色”最权威的接口

SDK 提供运行时查询，无需从型号名推断：

```cpp
mmind::eye::Frame2D frame;
camera.capture2D(frame);
mmind::eye::ColorTypeOf2DCamera t = frame.colorType();   // Monochrome 或 Color
```

即 `enum class ColorTypeOf2DCamera { Monochrome, Color }`。
`colorType()` 返回 `Monochrome` 即单色相机。

### 方式 C · 查询型号 / 序列号 / 硬件版本 / 固件版本（官方接口）

官方 ROS 2 接口内部使用的就是 SDK 的 `getCameraInfo()`：

```cpp
mmind::eye::CameraInfo info;
camera.getCameraInfo(info);
// info.model / info.serialNumber / info.hardwareVersion / info.firmwareVersion ...
```

对应命令行（无需写代码，本机可用）：

```bash
source /opt/ros/humble/setup.bash && source ~/colcon_ws/install/setup.bash
ros2 service call /device_info mecheye_ros_interface/srv/DeviceInfo "{}"
```

> 必须 source `~/colcon_ws`（`mecheye_ros_interface` 装在那里），
> 否则 ros2 报 `The passed service type is invalid`。

### 方式 D · 最省事

- 相机机身铭牌；
- Mech-Eye Viewer 连接后界面显示的型号；
- 本仓库脚本：`python3 scripts/setup_mecheye.py --check`。

## 五、一句话汇报稿

> 该 Mech-Eye PRO XS 只能输出单色 2D 图像，原因是其 2D 图像传感器为单色，
> 官方规格表明确标注 `2D image color: Monochrome`，且该系列无任何彩色物料编码版本。
> ROS 话题 `/mechmind/color_image` 之所以是三通道 bgr8，是因为官方 ROS 2 接口
> 无条件调用了 SDK 的 `getColorImage()`，而该函数在单色相机上按
> `Blue = Gray, Green = Gray, Red = Gray` 把灰度复制成三通道；接口从未检查
> `colorType()`，也没有 MONO8 分支。实测三通道逐像素相同，与该公式一致。
> 因此这不是故障，也没有软件开关可开启彩色。
