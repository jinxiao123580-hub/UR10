# 2026-09-17 视觉候选 + 人工修正抓取

## 结论

完成了一次真机抓取、提升和原位放回闭环，但它不是全自动视觉抓取：最初从单个可见
侧面推断的物块中心明显偏离，用户现场手动将夹爪修正到正确位置后才抓取成功。

## 执行记录

1. 视觉候选中心为 base `[0.63025,-0.09923,0.01388] m`。保持 TCP Z 和姿态不变，
   用 URScript `movel` 水平移动 `86.6 mm`；最终位置误差 `0.127 mm`。
2. 用户观察该位置“偏了很多”，指出修正方向为 base `X+ / Y-`，随后手动将 TCP 放到
   `[0.66161,-0.11659,0.30468] m`。视觉候选与实际抓取中心 XY 相差 `35.84 mm`。
3. 从人工修正位置沿 base Z 下降 `20 mm`，最终误差 `0.327 mm`。
4. Robotiq 以 `speed=80 / force=60` 闭合，停在 `POS=102`，`OBJ=2`、`FLT=0`；
   用户确认物块被夹住。
5. 沿 base Z 提升 `20 mm`，最终误差 `0.221 mm`；安全监控 200 帧无异常，提升后
   夹爪仍为 `OBJ=2`。用户确认物块离地并被稳定抓起。
6. 原路下降 `20 mm`，最终误差 `0.267 mm`；安全监控 200 帧无异常。夹爪低速张开到
   `POS=3`，`FLT=0`，物块原位放回。

机器人运动使用控制器原生 URScript `movel`，没有运行禁用的流式 IK，也没有运行
`ur_pick_place_full.py`，没有写入其未验证的 8 kg 负载。所有阶段均保持安全状态
`NORMAL`。
