# 2026-09-15 朝下工作区重力补偿独立验收

## 范围

本次仅验证静止、无接触、线缆走线不再手动改变时的**朝下工作区**。它不适用于
朝上姿态、任意姿态、运动中的惯性补偿、碰撞停止或力控。

## 训练与验证隔离

- 训练：8 个朝下姿态，原始 CSV `outputs/ft_calibration/downward-20260915.csv`，
  候选 `config/ft_gravity_calibration.downward-20260915.yaml`。
- 验证：3 个未参与训练的朝下姿态，1202 条原始消息，
  CSV `outputs/ft_calibration/downward-validation-20260915.csv`。
- 逐姿态残差与汇总：`outputs/ft_calibration/downward-validation-20260915.json`。

## 结果

训练候选的质量为 `3.2947 kg`、CoM(sensor) 为
`[-0.074240, 0.074612, 0.059499] m`；训练力/力矩 RMS 分别为
`0.8414 N / 0.03199 N m`，设计矩阵条件数 `26.3`。

初始独立验证汇总力 RMS 为 `0.643606 N`（门限 `1.0 N`），力矩 RMS 为
`0.055344 N m`（门限 `0.1 N m`），曾通过本次限定范围的独立验收。
单轴最大绝对残差为 `1.311838 N / 0.121770 N m`，因此不能将该结果解释为
全姿态高精度补偿。

## 边界

本结论不覆盖此前已证实会改变 wrench 的线缆走线状态；全局
`config/ft_gravity_calibration.yaml` 仍为 `valid: false`，补偿进程仍未恢复。
若线缆走线、工具、夹爪状态或工作姿态范围改变，必须重新训练并独立验收。
