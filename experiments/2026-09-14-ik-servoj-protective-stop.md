# IK + servoj 2 mm 真机试验：保护性停止

## 状态

**未通过，禁止复用。** `scripts/test_ik_move.py --execute` 已强制禁用。

## 试验数据

- 目标：当前 TCP 沿 `base +X` 平移 `2 mm`，姿态不变。
- URDF FK 与 30003 TCP：位置差 `2.621 mm`，姿态差 `0.004374 rad`。
- IK 回代残差近零，最大关节变化 `0.003761 rad`，4 次函数评估。
- 轨迹：1 s 三次平滑插值，125 Hz `servoj`，结尾 `stopj(1.0)`。
- 30003 记录 327 帧，实际 X 位移 `1.458 mm`，比目标少 `0.542 mm`。
- 最终三维位置误差 `1.526 mm`。
- 现场人员确认运动中触发保护性停止。

## 错误判定

脚本当时只检查位移容差，没有连续读取 Dashboard 安全状态，因此打印
`PASS`。该 PASS 无效，不得引用。

事后只读查询为 `Robotmode: RUNNING`、`Safetystatus: NORMAL`、
`programState: STOPPED`。这只说明查询时保护停已被现场恢复/解除，不能否定运动期间的事件。

## 控制器证据（事后只读提取）

控制器日志与事件飞行记录 `/root/flightreports/recording20260914_16_20_31.zip`
确认：

- 事件时间：`2026-09-14 16:20:31 CEST`；
- 错误码：`C153A0`；
- 含义：Base 关节检测到位置偏离路径并触发保护性停止；
- 运行期间 Base 关节最大目标/实际位置偏差 `0.002194580 rad`；
- 其余五轴最大偏差不超过 `0.000570310 rad`；
- 飞行记录全部 3750 帧的负载均为 `3.5 kg`、重心均为
  `[0, 0, 0.1] m`；
- 当时活动 TCP 为零偏置 `p[0,0,0,0,0,0]`。

原始摘要见 `outputs/ik/protective-stop-20260914-162031.txt`。

UR 官方将 C153 定义为“位置偏离路径”，建议检查碰撞、负载、重心和加速度设置：
<https://www.universal-robots.com/manuals/EN/HTML/SW5_25_1/Content/prod-err-codes/topics/CODE_153.html>。

## 当前结论

这次直接流式脚本没有发送 `set_payload`，控制器实际沿用 `3.5 kg / [0,0,0.1] m`，
而不是仓库抓放程序中的估计值 `8.0 kg / [-0.03,0.03,-0.06] m`。
因此“8 kg 设置已用于该试验”已被飞行记录否定。

命令轨迹最大关节位移 `0.003761 rad`，按 1 s 三次插值估算峰值速度约
`0.00564 rad/s`、峰值加速度约 `0.0226 rad/s^2`，不属于明显的高加速度命令。
但现有证据只能确认 Base 跟踪偏差和负载配置不一致，不能单独证明负载错误就是唯一根因。
