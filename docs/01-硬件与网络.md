# 01 · 硬件与网络

## 1. 网络拓扑

```
   ┌───────────────┐   网线     ┌──────────────────────┐
   │  电脑 (Ubuntu)│◀─────────▶│  UR 控制柜 Network 口 │
   │ enp0s31f6     │           │                      │
   │ 192.168.1.10  │           │  192.168.1.3 (UR10)  │
   └───────────────┘           └──────────────────────┘
            同一个二层网络，直连，不用交换机也行
```

| 设备 | IP | 说明 |
|---|---|---|
| UR10 控制柜 | `192.168.1.3` | 示教器上可查/改（设置 → 网络） |
| 电脑主板网口 | `192.168.1.10/24` | 静态，跑机械臂专用 |

> ⚠️ 电脑上如果还插着 USB 网卡上网（如 `10.115.3.x`）并跑着 **sing-box / Clash 代理**，
> 去机器人的流量可能被代理劫持。`scripts/network_setup.sh` 会加策略路由把
> `192.168.1.0/24` 排除在代理之外。

## 2. 一键配网

```bash
sudo bash scripts/network_setup.sh
```

它做四件事：
1. 检查网口载体（`carrier=1` 表示网线插好、控制柜已开机约 1 分钟）；
2. 用 `nmcli` 把静态 IP `192.168.1.10/24` **固化**到 NetworkManager（重启不丢）；
3. 加策略路由，让 `192.168.1.0/24` 绕过代理隧道；
4. 验证 `ping 192.168.1.3` + 端口探测。

参数可覆盖：`sudo bash scripts/network_setup.sh [网口] [本机IP] [机器人IP]`

**临时方案**（不改 NetworkManager，重启失效）：

```bash
sudo bash scripts/setup_pc_ip.sh
```

## 4. 机器人接口 / 端口全表（实测）

| 端口 | 名称 | 方向 | 用途 |
|---|---|---|---|
| **29999** | Dashboard Server | 电脑 → 机器人 | 文本命令：`power on` / `brake release` / `play` / `stop` / `programState`（**每条返回一行**） |
| **30001** | Primary Client | 机器人 → 电脑 | **只读状态流**（10Hz），二进制子包，含关节角、TCP 位姿（type=4） |
| 30002 | Secondary Client | 电脑 → 机器人 | **发 URScript**（本项目机械臂运动走这里） |
| **30003** | Real-time Client | 机器人 → 电脑 | **实测 125.02Hz**，固定 1220B 状态帧，可用于十毫秒级状态读取 |
| 30011 | Local Primary | 机器人 → 电脑 | 实测混合消息约 20.62Hz，包长不固定，不作为恒力状态通道 |
| 30012 | Local Secondary | 双向 | 实测混合消息约 10.19Hz，包长不固定，不作为恒力状态通道 |
| **30013** | Local Real-time | 机器人 → 电脑 | **实测 124.82Hz**，固定 1220B 状态帧，可作为 30003 备选 |
| **63352** | Robotiq 夹爪守护进程 | 电脑 → 机器人 | **Robotiq ASCII 协议**（夹爪开合走这里，见 `docs/04`） |
| 50002 | FZI External Control URCap | 电脑 → 机器人 | 装了这个 URCap 但**当前未运行**（端口关），本项目不用 |
| 22 | SSH | 电脑 → 机器人 | root 登录 `root/easybot`，见 `docs/07` |

### Real-time Client 实测（2026-09-11）

`scripts/probe_ur_realtime.py --duration 5` 的连续收包结果：

| 端口 | 帧数 | 频率 | 最大帧间隔 | 包长 |
|---|---:|---:|---:|---|
| 30003 | 579 | 125.02Hz | 8.39ms | 固定 1220B |
| 30011 | 100 | 20.62Hz | 100.80ms | 9/24/55/181/682/716/1352B 混合 |
| 30012 | 52 | 10.19Hz | 100.74ms | 24/55/682/1352B 混合 |
| 30013 | 573 | 124.82Hz | 8.19ms | 固定 1220B |

30003/30013 均持续输出完整帧，尾部残留 0B。端口 connect 成功不是本项
验收依据，上表来自持续按大端 uint32 包长拆帧后的有效帧统计。

### Dashboard 常用命令速查

```bash
# 通用格式：往 29999 发一行文本
python3 - <<'EOF'
import socket
s = socket.create_connection(("192.168.1.3", 29999), timeout=3)
s.recv(4096)                      # 先收欢迎语
s.sendall(b"robotmode\n")
print(s.recv(4096).decode())
EOF
```

| 命令 | 作用 |
|---|---|
| `robotmode` | 机器人模式（RUNNING / POWER_OFF / IDLE…） |
| `safetystatus` | 安全状态（NORMAL / PROTECTIVE_STOP…） |
| `programState` | 程序运行状态（PLAYING / STOPPED） |
| `get loaded program` | 当前加载的程序 |
| `power on` / `power off` | 上电 / 断电 |
| `brake release` | 松刹车（**松完机械臂就会垂下，务必扶住/垫好**） |
| `play` / `pause` / `stop` | 播放 / 暂停 / 停止程序 |
| `close safety popup` | 关掉安全提示弹窗 |
| `PolyscopeVersion` | 控制器版本 |
| `get robot model` / `get serial number` | 机型 / 序列号 |

> 本仓库的 `ur_link` 已把上述命令包成了 ROS 服务，见 `docs/02`。

## 5. 开机上电标准流程

**示教器操作**（推荐，最直观）：

1. 控制柜电源 → 等待示教器启动（约 1 分钟）；
2. 旋开**急停**按钮（如已按下）；
3. 示教器右下角/左上角 **ON** → 机器人上电（听到"咔"）；
4. **START** → 松刹车。⚠️ 松刹车后机械臂会因重力下垂，**先扶住或确认姿态稳定**；
5. 确认状态：
   ```bash
   python3 scripts/diagnose.py
   # robotmode 应为 RUNNING，safetystatus 应为 NORMAL
   ```

**纯命令行上电**（无人值守/脚本化）：

```bash
source /opt/ros/humble/setup.bash && source ~/ros2_ws/install/setup.bash
ros2 service call /ur_link/dashboard/close_safety_popup std_srvs/srv/Trigger
ros2 service call /ur_link/dashboard/power_on           std_srvs/srv/Trigger
ros2 service call /ur_link/dashboard/brake_release      std_srvs/srv/Trigger   # ⚠ 扶住机械臂
```

## 6. 常见网络故障

| 症状 | 原因 | 解决 |
|---|---|---|
| `ping` 不通、`carrier=0` | 网线没插好 / 控制柜没开机 / 插错口（要插 **Network** 口，不是 teach pendant 口） | 检查线、等控制柜启动 1 分钟 |
| `ping` 通但端口全连不上 | 电脑 IP 与机器人不同网段 | 确认电脑是 `192.168.1.x` |
| 时通时断、偶发超时 | 电脑上代理（sing-box/Clash）抢路由 | 跑 `network_setup.sh` 加策略路由；或临时 `ip route add 192.168.1.0/24 dev enp0s31f6` |
| 端口能连、命令没反应 | 机器人保护性停止 / 本地模式 | `robotmode`、`safetystatus` 查一下；示教器关弹窗 |
| 电脑 WiFi 也跟着断 | 默认路由被改到机械臂网口 | `network_setup.sh` 已避免设置网关（`ipv4.gateway ""`） |
