# 02 · 官方 ROS 2 驱动

当前 UR10 真机驱动使用 Universal Robots 官方 `ur_robot_driver 2.14.0`。本机旧工作区会
覆盖官方描述包，所以必须在干净 ROS 环境中启动。机器人示教器须处于 Remote Control，且
已加载与驱动对应的 External Control 程序后才能建立控制通道。

```bash
cd ~/UR10
env -u AMENT_PREFIX_PATH -u CMAKE_PREFIX_PATH -u COLCON_PREFIX_PATH \
  bash --noprofile --norc -c '
source /opt/ros/humble/setup.bash
ros2 launch ur_robot_driver ur_control.launch.py \
  ur_type:=ur10 robot_ip:=192.168.1.3 \
  kinematics_params_file:=/home/jx/UR10/config/ur10_factory_calibration.yaml \
  launch_rviz:=false
'
```

已验证的工厂运动学文件为 `config/ur10_factory_calibration.yaml`；录制姿态的 FK 对控制器
TCP 最大偏差为 `0.017312 mm / 0.004694°`。坐标变换必须使用 `base`，不能把 `base_link`
当作控制器基坐标。

启动成功后先只读确认：

```bash
source /opt/ros/humble/setup.bash
ros2 topic echo /joint_states --once
ros2 control list_controllers
```

本项目没有“任意复制即可执行”的 ROS 运动命令。任何轨迹必须先有资料依据、离线门禁、
假硬件验证和单段低速验收；具体安全边界以 [`../HANDOVER.md`](../HANDOVER.md) 顶部为准。
