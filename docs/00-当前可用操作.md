# 当前可用操作

本页只列出在当前 UR10 CB3、ROS 2 Humble 环境中可直接执行且已验收的入口。执行前先读
[`../HANDOVER.md`](../HANDOVER.md) 的 `0A. 最新接手状态`；它优先于任何旧实验记录。

## 只读体检

```bash
cd ~/UR10
python3 scripts/diagnose.py
python3 scripts/verify_ur_payload.py
python3 scripts/monitor_ur_safety.py --duration 3

# 第 2 节：读关节角 / TCP 位姿 / robotmode / safetystatus（只读，不发运动命令）
python3 scripts/read_ur_state.py
python3 scripts/read_ur_state.py --watch --hz 5      # 连续显示，配合示教器点动对照
```
```

相机验证必须在相机终端已启动后执行；重启后完整流程如下：

```bash
# 终端 A：启动相机
cd ~/UR10
source /opt/ros/humble/setup.bash
source ~/colcon_ws/install/setup.bash
ros2 launch ~/colcon_ws/src/mecheye_ros2_interface/launch/start_camera_ur10.py

# 终端 B：验证相机接口并保存 JSON
cd ~/UR10
source /opt/ros/humble/setup.bash
source ~/colcon_ws/install/setup.bash
python3 scripts/validate_mecheye_capture.py
```

这些命令不移动机械臂。ATI 是单消费者；需要 ATI 数据时，只启动一个
`ati_netft_node.py` 实例。

## 夹爪开合反馈验证

只移动夹爪、不移动机械臂，实时记录 `POS/PRE/OBJ/STA/FLT`，结束时自动恢复张开：

```bash
cd ~/UR10
python3 scripts/verify_gripper_motion.py --duration 2 --interval 0.10
```

结果保存到 `outputs/gripper/motion-verification.json`。本机实测空夹闭合过程为
`POS=3 → 22 → 103 → 191 → 230`，目标 `PRE=255`；完全张开为 `POS=3`。空夹结束时
`OBJ=3` 是“到达目标但未检测到物体”，不能当作抓取成功。

## 左指尖 TCP 标定（课程第 4 节）

下列命令只读 UR 的实时状态，不发送运动命令，也不写入控制器 TCP。固定闭合左指尖在一个
硬质参考点上，通过示教器改变姿态；前 9 个样本拟合，最后 3 个样本独立验收。

```bash
cd ~/UR10
python3 scripts/calibrate_fingertip_tcp.py \
  --samples 12 --holdout 3 --duration 1 --tcp-name left_fingertip_closed
```

只有条件数和留出集残差均通过脚本门限，才能把结果用于下一步工具坐标验证；它不等于授权
机器人沿新 TCP 运动。

## 位置式抓放示例（无力控）

仓库保留一个位置式抓放示例，使用控制器原生 `movel`（30002）和电脑直控 Robotiq ASCII
（63352），不使用 ATI、重力补偿、碰撞力判定或 ROS 旧话题桥。它带有每段到位检查、夹爪
`OBJ=2` 检查和失败即停；示例点位只是历史记录，必须先在现场确认物体、姿态、障碍物和
安全高度。

先做离线检查：

```bash
cd ~/UR10
python3 scripts/position_pick_place.py \
  --poses config/position_pick_place.example.json --dry-run
```

真机执行需要现场人员在急停旁，并明确加上 `--poses` 指向已重新确认的点位文件；脚本默认
不会执行运动，且不设置或声称测量机器人负载：

```bash
python3 scripts/position_pick_place.py \
  --poses /absolute/path/to/verified_pick_place.json
```

这是位置抓放演示，不是视觉自主抓取，也不提供力控或碰撞停止。当前仅完成 dry-run，尚未
完成本机真机抓放验收。若 `OBJ` 不是 `2`，脚本会停止搬运。

### 固定点演示模式（不要求夹持确认）

仅用于课程演示时，可显式加入 `--demo`。该模式会忽略 `OBJ`，即使没有夹住物体也继续
抬升、搬运、张开和离开；它不代表抓取成功，也不使用力控。重启后完整指令如下：

```bash
# 终端 1：网络和机器人只读检查
cd ~/UR10
ip addr
ping -c 3 192.168.1.3
python3 scripts/diagnose.py

# 终端 2：确认夹爪开合反馈（不动机械臂）
cd ~/UR10
python3 scripts/verify_gripper_motion.py --duration 2 --interval 0.10

# 终端 3：固定点位置演示；现场有人、急停可用
cd ~/UR10
python3 scripts/position_pick_place.py \
  --poses config/position_pick_place.example.json \
  --height 0.05 --speed 0.02 --acceleration 0.05 \
  --demo
```

演示结束后检查：

```bash
cd ~/UR10
python3 scripts/diagnose.py
python3 scripts/check_current_docs.py
```

若要把物块从终点搬回起点，在第一轮完成且夹爪张开后，重复演示命令并加入 `--swap`：

```bash
python3 scripts/position_pick_place.py \
  --poses config/position_pick_place.example.json \
  --height 0.05 --speed 0.02 --acceleration 0.05 \
  --demo --swap
```
