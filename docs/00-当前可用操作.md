# 当前可用操作

本页只列出在当前 UR10 CB3、ROS 2 Humble 环境中可直接执行且已验收的入口。执行前先读
[`../HANDOVER.md`](../HANDOVER.md) 的 `0A. 最新接手状态`；它优先于任何旧实验记录。

## 只读体检

网页控制台位于`http://127.0.0.1:8080/`，2026-10-27已接入新手眼与工厂参数模型。页面下方“手眼标定与离线 IK”显示标定版本、独立闭环指标和验证记录；可读取当前关节快照或加载离线示例，选择`base → tool0`或`base → 相机`目标后求解，紫色模型显示离线候选。相机目标使用完整手眼变换，并限定完整位姿任务。

pose/axis缓存支持抽样播放、暂停、结束；“清除预览”隐藏紫色模型。实时关节和TCP读数始终来自机器人回读。新面板只有离线计算与预览入口，不发送运动指令；所查碰撞对不是完整环境验收。更新后刷新浏览器即可，运行参数或模型变化时页面将提示重新验收与重载。

六轴曲线已改为本地Canvas绘图，力和力矩分别使用N、N·m量程，不依赖外部CDN；可切换原始、补偿、补偿+低通。补偿进程恢复后已实测三个话题都有连续数据。相机重新安装后，旧质量/重心及偏置参数仅作显示预览，原补偿残差精度不再沿用，不用于运动保护。

页面底部另有“末端单步点动·真机”面板，与离线IK分开。现场确认空间后勾选启用，才能点击前/后/左/右/上/下或Rx/Ry/Rz正负旋转。默认1mm/0.5°，最大单步5mm/2°；可选base或当前TCP坐标系，TCP模式按钮改为明确的TCP±X/Y/Z标签。每次点击仅一段控制器原生低速movel，无排队；先检查控制器状态、当前TCP偏移、工厂模型FK、25点路径IK、限位、奇异性和选定碰撞对，再复核状态后发送。切走页面、心跳中断或取消会停止本次点动，软件停止不代替硬件急停。

本网页点动只完成18项模拟控制器场景和界面检查，尚未真机运动验收；部署与测试期间未发送真机运动。单次请求及结果写入`outputs/dashboard/motion-jobs/`。证据在`~/.handoff/reports/20261027-dashboard-motion/`。

后续输入/反馈更新：平移量、旋转量已改为可输入小数的数字框，仍限制0.5–5mm/0.5–2°；输入数值后点击相应方向，每次只执行一步。点击立即显示提交状态，随后显示路径校验进度、请求量、当前TCP毫米坐标及实际位移/转角。超限错误会保留，不会被旧“完成”状态覆盖。启用真机点动会暂停并清除紫色离线预览，关闭点动后恢复离线功能。

只读排查已观察到8次用户提交的X方向1/5mm点动记录到位；这不是所有方向及停止功能的完整真机验收。新输入与反馈逻辑使用模拟控制器和浏览器验证，未在排查中新增真机点动。证据：`~/.handoff/reports/20261027-jog-input-feedback/`。服务更新后请刷新页面并重新启用点动。

## 夹爪开合反馈验证

只移动夹爪、不移动机械臂，实时记录 `POS/PRE/OBJ/STA/FLT`，结束时自动恢复张开：

```bash
cd ~/UR10
python3 scripts/verify_gripper_motion.py --duration 2 --interval 0.10
```

结果保存到 `outputs/gripper/motion-verification.json`。本机实测空夹闭合过程为
`POS=3 → 22 → 103 → 191 → 230`，目标 `PRE=255`；完全张开为 `POS=3`。空夹结束时
`OBJ=3` 是“到达目标但未检测到物体”，不能当作抓取成功。

## 左指尖 TCP 标定（课程第 4 节）

下列命令只读 UR 的实时状态，不发送运动命令，也不写入控制器 TCP。固定闭合左指尖在一个
硬质参考点上，通过示教器改变姿态；前 9 个样本拟合，最后 3 个样本独立验收。

```bash
cd ~/UR10
python3 scripts/calibrate_fingertip_tcp.py \
  --samples 12 --holdout 3 --duration 1 --tcp-name left_fingertip_closed
```

只有条件数和留出集残差均通过脚本门限，才能把结果用于下一步工具坐标验证；它不等于授权
机器人沿新 TCP 运动。

## 位置式抓放示例（无力控）

仓库保留一个位置式抓放示例，使用控制器原生 `movel`（30002）和电脑直控 Robotiq ASCII
（63352），不使用 ATI、重力补偿、碰撞力判定或 ROS 旧话题桥。它带有每段到位检查、夹爪
`OBJ=2` 检查和失败即停；示例点位只是历史记录，必须先在现场确认物体、姿态、障碍物和
安全高度。

先做离线检查：

```bash
cd ~/UR10
python3 scripts/position_pick_place.py \
  --poses config/position_pick_place.example.json --dry-run
```

真机执行需要现场人员在急停旁，并明确加上 `--poses` 指向已重新确认的点位文件；脚本默认
不会执行运动，且不设置或声称测量机器人负载：

```bash
python3 scripts/position_pick_place.py \
  --poses /absolute/path/to/verified_pick_place.json
```

这是位置抓放演示，不是视觉自主抓取，也不提供力控或碰撞停止。当前仅完成 dry-run，尚未
完成本机真机抓放验收。若 `OBJ` 不是 `2`，脚本会停止搬运。

### 固定点演示模式（不要求夹持确认）

仅用于课程演示时，可显式加入 `--demo`。该模式会忽略 `OBJ`，即使没有夹住物体也继续
抬升、搬运、张开和离开；它不代表抓取成功，也不使用力控。重启后完整指令如下：

```bash
# 终端 1：网络和机器人只读检查
cd ~/UR10
ip addr
ping -c 3 192.168.1.3
python3 scripts/diagnose.py

# 终端 2：确认夹爪开合反馈（不动机械臂）
cd ~/UR10
python3 scripts/verify_gripper_motion.py --duration 2 --interval 0.10

# 终端 3：固定点位置演示；现场有人、急停可用
cd ~/UR10
python3 scripts/position_pick_place.py \
  --poses config/position_pick_place.example.json \
  --height 0.05 --speed 0.02 --acceleration 0.05 \
  --demo
```

演示结束后检查：

```bash
cd ~/UR10
python3 scripts/diagnose.py
python3 scripts/check_current_docs.py
```

若要自动往返循环，使用 `--pingpong` 和 `--cycles`。例如往返 4 轮：

```bash
python3 scripts/position_pick_place.py \
  --poses config/position_pick_place.example.json \
  --height 0.05 --speed 0.02 --acceleration 0.05 \
  --demo --pingpong --cycles 4
```
