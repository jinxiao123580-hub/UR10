# 03 · 机械臂控制

## 当前入口

当前真机控制的基础是 Universal Robots 官方 ROS 2 驱动，而不是仓库中保留的历史 ROS 话题桥。
启动与只读确认见 [`02-官方ROS2驱动.md`](02-官方ROS2驱动.md)。

本项目目前没有通用的“输入两个点即可运动”的可执行教程。原因是目标位置、TCP、负载、障碍物、
控制器状态和安全门禁都必须针对实验逐项验收；把任意旧示例改数字后运行不安全，也不属于当前
支持接口。

## 允许的工作顺序

1. 查官方建议和适用控制器，记录版本与本机 CB3 的差异。
2. 使用正确的 `base` 坐标与已验证的
   `config/ur10_factory_calibration.yaml` 做离线运动学、限位和路径验证。
3. 用官方假硬件验证控制器与轨迹消息。
4. 现场只做单段低速运动，持续监控安全状态；完成后保留日志和实际误差。
5. 再逐步扩大为多段任务，任何一步未验收即停止。

## 当前不可用入口

- 电脑端流式 IK 的真机执行入口因 `C153A0` 保护停持续禁用。
- 保留的旧话题桥和历史抓放代码不构成真机运动接口。
- 任何使用未经验证负载的运动流程均不可运行。

状态、硬件限制和下一步以 [`../HANDOVER.md`](../HANDOVER.md) 顶部为准。
