# 视觉自主抓取验收（2026-09-24）

这是一条针对 UR10、Robotiq 2F、Mech-Eye PRO XS、ATI Net F/T 的实验流程。它不是通用
工业安全认证；全程需现场人员和急停。

## 外部前置项

- Ubuntu 22.04、ROS 2 Humble、`python3-opencv`、NumPy、SciPy、Pinocchio；
- Mech-Eye SDK **2.5.0**（厂商安装包，因许可不随仓库分发）；
- 相机 ROS 包固定为 MechMind 官方仓库提交 `0123b8bea87ef865958417630088e9c5e48fdb44`。

在已安装 SDK、已 source ROS 后，恢复相机工作区：

```bash
cd ~/UR10
source /opt/ros/humble/setup.bash
bash scripts/bootstrap_mecheye_workspace.sh
```

该脚本会获取固定官方提交、应用仓库中保存的 UR10 直连补丁、安装启动文件并构建。仓库内
`ros2_ws/src/` 已包含数字孪生和 `ur_link` 的全部源码；`ros2_ws/build`、`install`、`log`
是可再生构建产物，不入库。

## 完整验收命令

物块换位、夹爪张开、急停就绪后：

```bash
cd ~/UR10
source /opt/ros/humble/setup.bash
source ~/colcon_ws/install/setup.bash
bash scripts/start_dashboard.sh
FASTDDS_BUILTIN_TRANSPORTS=UDPv4 python3 scripts/auto_cube_pick_place.py --execute
```

流程会：检测 `10×7` 棋盘格；检测棋盘旁的 50 mm 物块；在悬停位只用物块点云复拍；若首次与
复拍中心差异大，则 `0°/+25°/-25°` 三视角环视并保存原始云；中心跨视角一致性、模型残差和
有界中心修正均通过后才下降。

抓取中心定义为用户实测的 tool0 向工具 `+Z` 220 mm 的夹取中心。当前验收策略把该中心放在
**点云顶面上方 25 mm**。夹爪必须返回 `OBJ=2` 才搬运。

放置不使用固定低位：先到安全高度，再以 2 mm 步长下探；`/ft_sensor/wrench_raw` 的相对 Fz
较静态基线突变至少 8 N 时发送 `stopj`、张开并抬离。若没有力突变则保持夹紧并停止。
