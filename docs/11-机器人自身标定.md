# 机器人自身标定（已验证结论）

本文只收录已经真机验证、可直接用于当前项目的结论。负载、
TCP、力坐标变换等未完成项见 [`docs/14`](14-待办与已知问题.md)；
实验过程和失败路线见 [`experiments/`](../experiments/README.md)。

## 标称 URDF 正运动学

当前继续使用 UR10 标称 URDF，不手工填入控制器
`calibration.conf` 的 delta 参数。

真机对比证据：

| 日期 | 对比 | 位置偏差 | 姿态偏差 |
|---|---|---:|---:|
| 2026-09-10 | 标称 URDF `base→tool0` vs. 机器人 TCP | `2.6 mm` | `0.0035 rad` |
| 2026-09-11 | 标称 URDF `base→tool0` vs. 30001 TCP | 最大分量 `2.2 mm` | 轴角最大分量 `0.0052 rad` |

两次结果一致，未发现漂移。对当前厘米级抓放和课程演示，
标称 URDF 可用。这不代表已达到亚毫米精度。

## 坐标系结论

- UR 机器人自报 TCP 和 `movel` 目标使用 `base`。
- URDF 中 `base_link` 相对 `base` 绕 Z 轴旋转 180°，X/Y 镜像。
- 2026-09-11 实测误用 `base_link` 时位置偏差 `1.2954 m`。
- 视觉、IK 和轨迹目标必须显式变换到 `base`。

```bash
source /opt/ros/humble/setup.bash
```

对齐”作为证据。

## 负载状态回读

当前 CB3 的 30003 固定 1220B 帧可直接回读活动负载：质量是整帧偏移
`1140` 的大端 double，重心 XYZ 是偏移 `1148` 起的三个大端 double。
2026-09-14 用 `scripts/verify_ur_payload.py` 连续读取 25 帧，均为：

```text
mass = 3.500000 kg
cog  = [0.000000, 0.000000, 0.100000] m
```

该结果与同日控制器保护停飞行记录的全部 3750 帧一致。它证明可以直接
核验 `set_payload` 是否生效，也证明当次 IK 试验没有使用仓库里估计的 8 kg
参数；**不代表 3.5 kg 是当前工具的正确负载**。

只读检查命令：

```bash
python3 scripts/verify_ur_payload.py
```

脚本的写入模式会先保存 JSON 并打印恢复命令，但写入和自动恢复分支尚未
真机验收。真实质量/重心由控制器负载向导测定前，不写入不同参数。
