# 11 · 机器人自身标定

## 已验证：工厂运动学

官方工厂标定文件为 `config/ur10_factory_calibration.yaml`。使用该文件的 FK 对控制器 TCP
最大偏差为 `0.017312 mm / 0.004694°`。机器人实际控制与视觉坐标均使用 `base`；不能用
`base_link` 代替。

当前官方驱动启动和只读确认见 [`02`](02-官方ROS2驱动.md)。

## 待完成：闭合左指尖 TCP

没有笔时，课程第 4 节以闭合左夹爪指尖作为笔尖替代。当前可执行的标定脚本只读取 UR 实时
状态、带静止门禁和留出验证，不发送运动命令：

```bash
cd ~/UR10
python3 scripts/calibrate_fingertip_tcp.py \
  --samples 12 --holdout 3 --duration 1 --tcp-name left_fingertip_closed
```

通过脚本的条件数和独立验证门限后，仍需以同一空间固定点复核不同姿态下的指尖一致性；在此之前
不能把新 TCP 用于既有抓放点或书写轨迹。

## 已验证：闭合左指尖 TCP（2026-09-21）

在示教器确认激活 TCP 为零/法兰的前提下，已使用固定尖点回转法完成左闭合指尖的位置标定。结果
在 `outputs/tcp_calibration/fingertip-20260921.json`：12 个有效样本、条件数 2.237，末 3 个留出
样本的 RMS/最大误差为 1.328/1.754 mm，数值门禁通过。所得 `tool0 -> left_fingertip_tcp` 平移为
`[0.046606, -0.008747, 0.258853] m`。

本机 UR 的 30003 不可达，但 30013 已实测连续输出 1220 B、125 Hz 实时帧；标定和 RViz 只读跟随
均显式使用 30013。该回转法只标定指尖**位置**，`left_fingertip_tcp` 的坐标轴暂继承 `tool0`，不能
据此推断夹持方向或直接授权实机抓取。RViz 中绿色球/TF 仅用于与实物指尖核对。
