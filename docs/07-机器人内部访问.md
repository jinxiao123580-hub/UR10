# 07 · 机器人内部访问（SSH 与程序文件）

> ⚠️ **慎用**。这一节能让你直接读写机器人控制器的文件系统。
> 改错文件可能导致机器人无法正常加载程序。**改之前先备份**，改完先小范围验证。
> 这不是日常操作必需的——日常控制用 `docs/03` / `docs/04` 就够了。

## 1. 为什么需要它

排查"示教器程序到底在跑什么"时，靠示教器界面猜是没用的。
SSH 进去**把程序文件原文捞出来看**，是唯一可靠的办法。
本项目最大的两个发现（`rq_activate()` 死锁、`cachedContents` 过期缓存）都是这么挖出来的。

## 2. 登录

```bash
ssh root@192.168.1.3
# 默认密码: easybot      （UR 出厂默认，未改过）
```

非交互式（脚本里用）：

```python
import paramiko
c = paramiko.SSHClient()
c.set_missing_host_key_policy(paramiko.AutoAddPolicy())
c.connect("192.168.1.3", username="root", password="easybot",
          timeout=8, allow_agent=False, look_for_keys=False)
print(c.exec_command("hostname")[1].read().decode())
```

> 需要本机装 `paramiko`（`pip install paramiko`），或直接用 `ssh` + `sshpass`。

登录后能看到的（实测）：

```
root@ur-2022300602:~# hostname
ur-2022300602
root@ur-2022300602:~# ps aux | grep -iE 'URControl|drivergripper'
root  3092  ./URControl                     ← 运动控制器
root  3063  ./drivergripper                 ← Robotiq 夹爪守护进程
```

## 3. 程序文件全在 `/programs/`

```bash
ls -lat /programs/ | head
#   jx_test.script      ← 脚本节点内容(扁平化后的 URScript)
#   jiazhua.urp         ← 程序本体
#   jiazhua.script      ← 该程序生成的完整脚本(含 URCap 76KB)
#   jiazhua.txt         ← 元信息
#   default_1.installation / default.variables
```

| 文件 | 是什么 |
|---|---|
| `*.urp` | **程序本体**（gzip 压缩的 XML，程序树 + Script 节点内容） |
| `*.script` | 程序**生成的完整 URScript**（含 URCap 注入的安装节点代码） |
| `*.installation` | **安装文件**（IO 配置、TCP、负载、URCap 配置） |
| `*.variables` | 全局变量 |
| `*.bak0/.old0` | 编辑器自动备份 |

## 4. 关键：`.urp` 是 gzip 压缩的 XML

不能直接 `cat`（会看到乱码）。解压方法（实测文件头 `1f8b0800` = gzip）：

```python
import paramiko, gzip

c = paramiko.SSHClient()
c.set_missing_host_key_policy(paramiko.AutoAddPolicy())
c.connect("192.168.1.3", username="root", password="easybot",
          allow_agent=False, look_for_keys=False)
sftp = c.open_sftp()

xml = gzip.decompress(sftp.open("/programs/jiazhua.urp", "rb").read()).decode("utf-8")
print(xml)
```

解压出来的结构（真实内容）：

```xml
<URProgram name="jiazhua" installation="default_1" ...>
  <kinematics status="LINEARIZED" .../>          <!-- 标定数据 -->
  <children>
    <MainProgram runOnlyOnce="true">
      <children>
        <Script type="File">
          <cachedContents>socket_open(&quot;192.168.1.10&quot;,30010,&quot;g&quot;) ...</cachedContents>
          <file>/programs/jx_test.script</file>
        </Script>
      </children>
    </MainProgram>
  </children>
</URProgram>
```

**这段就是答案**：脚本节点是 `type="File"`，同时带着一份 `cachedContents` 缓存。
两者不一致时，你改文件是白改的。

## 5. 写回程序文件（免示教器粘贴）

有了读写能力，就能**在电脑上改程序、直接推到机器人**，不用在示教器上手动粘贴：

```python
import paramiko, gzip

c = paramiko.SSHClient()
c.set_missing_host_key_policy(paramiko.AutoAddPolicy())
c.connect("192.168.1.3", username="root", password="easybot",
          allow_agent=False, look_for_keys=False)
sftp = c.open_sftp()

# 1) 先备份（重要！）
c.exec_command("cp /programs/jiazhua.urp /programs/jiazhua.urp.bak_$(date +%s)")

# 2) 读出 XML，改掉 cachedContents 里的脚本
xml = gzip.decompress(sftp.open("/programs/jiazhua.urp", "rb").read()).decode("utf-8")
new_xml = xml.replace(OLD_SCRIPT_ESCAPED, NEW_SCRIPT_ESCAPED)

# 3) 压缩写回
with sftp.open("/programs/jiazhua.urp", "wb") as f:
    f.write(gzip.compress(new_xml.encode("utf-8")))

# 4) 让示教器加载它（Dashboard 29999）
import socket, time
s = socket.create_connection(("192.168.1.3", 29999), timeout=3); s.recv(4096)
s.sendall(b"load /programs/jiazhua.urp\n"); time.sleep(0.5); print(s.recv(4096))
s.sendall(b"play\n"); time.sleep(0.5); print(s.recv(4096))
s.close()
```

**注意**：XML 里的脚本内容要把 `"` 转义成 `&quot;`、`<`/`>`/`&` 也要转义。

> 对抓放任务来说，**根本用不着改程序文件**——直连 63352 + ROS 就够了。
> 这一节的价值主要在**排查**和**改造现有示教器程序**。

## 6. 安装文件里的 URCap 配置

`default_1.installation`（同样是 gzip+XML）里有 URCap 的配置，例如：

```xml
<Contributed ownerId="com.fzi.externalcontrol" ... >
  <data key="port_nr" value="50002"/>            <!-- External Control 用的端口 -->
</Contributed>
<Contributed ownerId="com.robotiq.urcap.gripper"
             id="com.ur.robotiq.urcap.gripper.impl.GripperInstallationNodeService">
  <data key="gripper_current_limit_enabled" value="false"/>
  <data key="_models.Gripper1._openValueInMillimeters"  value="50.0"/>
  <data key="_models.Gripper1._closedValueInMillimeters" value="0.0"/>
  ...
</Contributed>
```

能查到的信息：装了哪些 URCap、External Control 监听哪个口、夹爪的 4 个逻辑夹爪配置
（`Gripper1~4`，开合行程 0~50mm）等。

已装 URCap 的 jar 位置：

```bash
ls /root/.urcaps/
# com.fzi.externalcontrol-1.0.5.jar
# com.robotiq.urcap.gripper-1.8.13.22852.jar
```

## 7. Dashboard 命令（29999）

见 `docs/01` 第 4 节的完整表格。最常用的：

```bash
python3 - <<'EOF'
import socket, time
def dash(cmd):
    s = socket.create_connection(("192.168.1.3", 29999), timeout=3); s.recv(4096)
    s.sendall((cmd + "\n").encode()); time.sleep(0.4)
    r = s.recv(4096).decode().strip(); s.close(); return r
for c in ["PolyscopeVersion", "get robot model", "get serial number",
          "robotmode", "safetystatus", "programState", "get loaded program"]:
    print(f"{c:22s} -> {dash(c)}")
EOF
```

实测输出：

```
PolyscopeVersion       -> URSoftware 3.15.8.106339 (六月 20 2022)
get robot model        -> UR10
get serial number      -> 2022300602
robotmode              -> Robotmode: RUNNING
safetystatus           -> Safetystatus: NORMAL
programState           -> STOPPED <未命名>
get loaded program     -> Loaded program: /programs/<未命名>.urp
```

## 8. 安全守则

1. **改文件前先备份**（`cp xxx.urp xxx.urp.bak_$(date +%s)`）；
2. 别动 `/root/.urcontrol/`、`/root/GUI/` 里的东西（控制器与界面本体）；
3. 改完先 `load` 看能不能正常加载，再 `play`；
4. 别在机器人运动时改程序文件；
5. 用完**改掉默认密码**（或至少知道这是台对内网敞开的设备）；
6. SSH 权限很大：`power off`、`brake release` 之类的操作别乱试。
