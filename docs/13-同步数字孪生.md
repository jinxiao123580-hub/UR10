# 11 · UR10 同步数字孪生

## 1. 目标与安全边界

本环境把真机 `/joint_states` 单向复制到独立的 `twin_*` TF 树，在 RViz 中实时显示
UR10、ATI Net F/T 与简化 Robotiq 二指夹爪。它是**只读数字孪生**：不发布
`/ur_link/urscript`，不连接 30002，不会向机械臂下发运动命令。

```text
UR10 30001 → ur_state_node → /joint_states
                              ↓
                    joint_state_bridge
                              ↓
             /digital_twin/joint_states → robot_state_publisher → twin_* TF → RViz
```

所有仿真 frame 使用 `twin_` 前缀，不会覆盖现有 `base`、`base_link` 或 `tool0`。

**Mech-Eye 暂不挂入模型。** P1 手眼标定尚未完成，当前没有可信的 `base→相机光学系`
外参。发布猜测的相机 TF 会让点云看似对齐但实际错误；标定完成后才能加入。

## 2. 构建

```bash
cd ~/UR10/ros2_ws
source /opt/ros/humble/setup.bash
source ~/ros2_ws/install/setup.bash
colcon build --symlink-install --packages-select ur10_digital_twin
```

## 3. 真机同步

确保机器人旁有人、急停可用。数字孪生本身只读，但现场仍按真机作业规范管理。

```bash
bash ~/UR10/scripts/start_digital_twin.sh real
```

脚本会检测现有 `ur_state_node`：已有则复用 `/joint_states`；没有则启动一份只读状态节点。
RViz 的 Fixed Frame 是 `world`，模型关节与 TF 都带 `twin_` 前缀。

另开终端做数值验收：

```bash
source /opt/ros/humble/setup.bash
source ~/ros2_ws/install/setup.bash
source ~/UR10/ros2_ws/install/setup.bash
python3 ~/UR10/scripts/check_digital_twin.py
ros2 run tf2_ros tf2_echo twin_base twin_tool0
```

## 4. 离线演示

没有真机也可以验证模型、RViz 与 TF：

```bash
bash ~/UR10/scripts/start_digital_twin.sh offline
```

离线节点以 20Hz 发布确定性的缓慢关节运动，只作用于数字孪生。

无图形界面时：

```bash
bash ~/UR10/scripts/start_digital_twin.sh offline --no-rviz
```

## 5. 当前模型精度

| 部件 | 状态 | 说明 |
|---|---|---|
| UR10 | 官方 `ur_description` | 使用 UR10 默认运动学与官方网格 |
| 六关节 | 真机同步 | 六个关节位置逐项复制，实测最大瞬时差约 `3.6e-5 rad` |
| ATI | 简化几何 | 固定在 `twin_tool0`，只用于表达安装链 |
| Robotiq | 简化几何 | 开口由 `gripper_opening` 参数设置，暂未读取 TCP 63352 的实时 POS |
| Mech-Eye | 未加入 TF | 等 eye-to-hand 标定得到真实外参后再加入 |
| 物理/碰撞 | 未启用 | 当前是 RViz 运动学孪生，不是动力学仿真 |

### 5.1 已有证据能确定的参数

| 对象 | 已确定 | 证据/限制 |
|---|---|---|
| UR10 | 连杆质量与惯量来自 ROS 2 `ur_description` 的 UR10 物理参数 | 这是型号默认值，不包含本机底座在车间中的测量位姿 |
| Mech-Eye PRO XS | `160 x 52 x 87 mm`，`0.8 kg` | 相机序列号 `RAM35238A3020004`、型号已由 GVCP 实机发现；尺寸/质量来自厂家 PRO XS 规格 |
| Robotiq 2F-85 | 厂家标准配置质量 `0.925 kg`，最大高度 `162.8 mm` | 本项目文档和程序按 2F-85 编写；仍需用本体铭牌/实测开口确认，标准数值不包含现场非标指尖和转接件 |
| ATI Net F/T | 标定 `SI-165-15`：`Fx/Fy=165 N`、`Fz=495 N`、`Tx/Ty/Tz=15 N·m` | 数据来自 `192.168.1.2/config.htm`；这是标定量程，不是可唯一确定外形和质量的机械型号 |

ATI 当前未 tare 时实测 `Fz` 约 `63.25 N`。若传感器 Z 轴与重力平行，只能粗略推断
其下游整套工装的重力等效质量约 `6.45 kg`；因安装姿态、零偏和线缆力未分离，
该数值不能写入动力学模型。

### 5.2 必须现场测量或标定的参数

| 参数 | 获取方法 | 验收标准 |
|---|---|---|
| `world -> base` | 测量机器人底座相对工作台/地面的 6D 位姿 | 在统一车间坐标下复测关键点 |
| `tool0 -> ATI -> gripper` | 核对 ATI 换能器本体铭牌，获取原厂 CAD；对现场转接盘、安装方向和指尖实测 | 法兰原点、XYZ 方向和 TCP 经实物触点验证 |
| `base -> camera_optical_frame` | eye-to-hand 手眼标定，15~25 个姿态 | 重投影误差合格后，用已知点做 `base` 坐标复测和实抓 |
| 质量、质心、惯量 | 厂家 CAD/BOM 优先；否则分件称重、重心试验和惯量辨识 | 静态力矩与多姿态重力模型残差验证 |

仅有“重量”不足以做物理仿真；每个刚体至少还需要质心和 `3 x 3` 惯量张量。
在上述数据验收前，URDF 中 ATI 与夹爪的几何不得用于碰撞判定或 Gazebo 动力学计算。

## 6. 参数

```bash
ros2 launch ur10_digital_twin digital_twin.launch.py \
  mode:=real \
  start_state_node:=false \
  robot_ip:=192.168.1.3 \
  tf_prefix:=twin_ \
  gripper_opening:=0.04 \
  rviz:=true
```

`gripper_opening` 单位为米，范围 `0~0.04`。真机状态同步链路刻意不包含控制反向通道；
后续若加入“仿真预演后下发真机”，必须增加人工确认、轨迹限位和碰撞检查，不能直接复用本节点反向发送。
