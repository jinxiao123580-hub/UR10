# 05 · 抓放状态与当前替代流程

## 当前结论

历史抓放脚本已禁用：它依赖保留的旧 ROS 桥，且其中的负载质量与重心没有独立测量验证。
因此本仓库目前没有可直接执行的“自动抓放”命令。

2026-09-17 已完成一次“视觉候选 + 人工修正”的物块抓起、提升和原位放回。夹爪状态为
`POS=102 / OBJ=2 / FLT=0`，但初始视觉候选与人工确认抓取中心的 XY 偏差为 `35.84 mm`。
这不是全自动视觉抓取的验收通过。

## 当前可执行的准备工作

```bash
cd ~/UR10
python3 scripts/diagnose.py
python3 scripts/verify_ur_payload.py
python3 scripts/monitor_ur_safety.py --duration 3
python3 scripts/validate_mecheye_capture.py
```

上述均为只读检查。手眼标定参数、独立验收数据和视觉定位的当前限制见
[`../HANDOVER.md`](../HANDOVER.md) 与 [`14-待办与已知问题.md`](14-待办与已知问题.md)。

## 恢复自动抓放前的准入条件

1. 在多个重新摆放的已知物体位置，独立测得视觉中心误差并通过门限。
2. 用负载向导或其他独立方法确认夹具和物体的质量、重心；不复用历史估计值。
3. 采用官方驱动/标准轨迹控制器，完成离线、假硬件、单段低速和安全状态监视验收。
4. 每次下降前保留安全悬停和人工急停条件，夹爪闭合后复核 `OBJ` 与提升结果。

原始证据在 `experiments/2026-09-17-视觉抓取闭环.md` 和 `outputs/`。历史代码仅为复盘，
不构成运行说明。
