# 05 · 完整抓放

把两条通道合起来：**ROS 管机械臂 + 电脑直控夹爪**。

## 1. 运行

```bash
cd ~/ur_learn/scripts          # 或你放脚本的目录
source /opt/ros/humble/setup.bash && source ~/ros2_ws/install/setup.bash

python3 ur_pick_place_full.py 1               # 1 轮：A(抓取点) → B(放置点)
python3 ur_pick_place_full.py 5               # 5 轮单向
python3 ur_pick_place_full.py 1 --swap        # 反向：B → A（把物体从终点抓回起点）
python3 ur_pick_place_full.py 4 --pingpong    # 往返 4 轮，物体在 A/B 之间来回搬
python3 ur_pick_place_full.py --forever       # 一直跑
```

**前置条件**：
1. `ur_command_node` 在跑（`ros2 run ur_link ur_command_node --ros-args -p robot_ip:=192.168.1.3`）；
2. 机器人已上电、已松刹车（`robotmode=RUNNING`）；
3. `~/ur_learn/poses.json` 里有标定好的 `pick` / `place`；
4. 物体已放在抓取点上；
5. **有人在急停旁**。

## 2. 三种方向模式

| 命令 | 每轮行为 | 物体最后在哪 | 适用 |
|---|---|---|---|
| 默认（无参数） | 第1轮A→B、第2轮A→B…（**单向**） | 永远在 B | 重复"从料位搬到成品位" |
| `--swap` | 每轮都 B→A（**反向**） | 永远在 A | 把已经搬到 B 的物体**搬回来** |
| `--pingpong` | 奇数轮 A→B、偶数轮 B→A（**往返**） | 来回搬 | 连续演示、压力测试 |

> 注意：**默认模式不会把物体从 B 抓回 A**。物体一旦到了 B，再跑默认模式就是空跑
> （去 A 抓了个空）。要把物体搬回来，用 `--swap`。

## 3. 一轮的八个步骤

```
① 移到取物点上方 (src + 50mm)     ← 安全高度，避免横向移动时撞到东西
② 下降到取物点   (src)
③ 夹爪闭合                       ← 关键：读 OBJ 判断有没有夹到
④ 抬起           (src + 50mm)
⑤ 移到放物点上方 (dst + 50mm)
⑥ 下降到放物点   (dst)
⑦ 夹爪张开（放下）
⑧ 抬起离开       (dst + 50mm)
```

实测输出：

### 怎么读这个日志判断成败

| 日志 | 含义 |
|---|---|
| `POS=104 OBJ=2 ✔ 夹住物体了` | **成功**。104 是手指被物体挡住的实际开口，OBJ=2 是硬件确认"夹到东西" |
| `POS=255 OBJ=3` + `⚠ 空抓！` | **抓空**：夹爪全闭到底、没碰到东西 → 物体不在抓取点，或标定偏了 |
| `POS=104 OBJ=3` | 手指被挡但硬件说没检测到 → 夹到夹具/桌面等非目标物，检查高度 |
| 第一步就报错连不上 | 网络/上电问题，先跑 `diagnose.py` |

## 4. 参数调优

打开 `ur_pick_place_full.py` 顶部：

```python
H = 0.05          # 安全高度(米)：取/放点上方抬多高。物高时调大（如 0.10）
V = 0.05          # 速度 5cm/s。熟练后可提到 0.15~0.25，一轮从 60s 缩到 20s
```

`g.close()` 默认力度 255（最大）。怕夹坏软物体：

```python
g.move(255, speed=255, force=120)     # 降力度
```

**调速度的顺序建议**：先 0.05 跑通 → 0.1 观察有无抖动/过冲 → 0.2 稳定后定稿。

## 5. 点位标定流程（换物体/换位置时）

```bash
# 1. 把物体放到新位置
# 2. 手推机械臂，让夹爪指尖刚好对准物体两侧（z 到物体中部，便于夹稳）
python3 scripts/ur_capture_pose.py pick

# 3. 移到放置点
python3 scripts/ur_capture_pose.py place

# 4. 先空跑一轮看轨迹（把物体拿走），再放物体正式跑
python3 scripts/ur_pick_place_full.py 1
```

**标定要点**：
- 抓取点 z 太低 → 夹爪压到桌面（`POS` 到不了位、可能报警）；
- 抓取点 z 太高 → 夹爪从物体上方掠过（`OBJ=3` 抓空）；
- 两个点姿态（rx,ry,rz）必须一致，否则移动过程中夹爪会歪。

## 6. 停止与异常处理

```bash
# 优雅停：Ctrl-C（脚本会停在当前位置，不松爪）
# 强制停：
ros2 service call /ur_link/dashboard/stop std_srvs/srv/Trigger
# 最保险：拍急停
```

跑多轮时如果中途 `⚠ 空抓`，脚本会打印警告但**继续跑**（方便观察）。
要"抓空立即停"，把那段改成：

```python
if obj == 3:
    print("   ⚠ 空抓，停止")
    break
```

## 7. 扩展方向

| 想做的事 | 怎么做 |
|---|---|
| 抓取点动态变化（视觉引导） | 把 `poses.json` 换成相机输出的实时位姿，其余不变 |
| 夹不同尺寸物体 | 用 `g.move(pos)` 按物体宽度设目标开口，而不是全闭 255 |
| 记录每次抓放结果 | 在循环里把 `POS/OBJ/时间` 追加写入 CSV |
| 多工位循环 | 把 `place` 换成点位列表，每轮 `pop` 一个 |
| 与产线节拍同步 | 在 `①` 之前等一个外部信号（GPIO/Modbus/ROS 话题） |
