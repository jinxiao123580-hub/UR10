# 06 · 入门：图片与开放授权来源清单

> 目的：给本套入门/标定文档配图，并**一份文件交代每张图的来源与授权**，方便合入仓库后
> 维护可追溯性。规则：只列**开放授权**（CC / 公有领域 / MIT 等）或**明确可引用**的来源；
> 商用量产产品照（例如优傲官网照片）默认**受版权保护**，不在仓库内热链或复制。

---

## 0. 你能怎么用这些图

| 方式 | 说明 | 何时用 |
|---|---|---|
| **热链接（hotlink）** | 文档里直接写 `<img src="...">` / `![](url)`，在线渲染 | 图源 URL 稳定、授权允许（Commons 等） |
| **下载放入仓库 `docs/assets/`** | 用 `git`/curl 下载到本地再引用 | 想离线可用、控制体积、规避外链失效 |

> **我在本套文档里用了"热链接"**（见第 1 节）。渲染差异说明：
> - 在 **GitHub 网页 / 浏览器**打开：能显示（只要联网）；
> - 在 **VSCode / Typora 等本地编辑器**预览：可能默认屏蔽远程图片而不显示。
> 如果你要**本机/离线也显示**，运行 `docs/scripts/fetch_images.ps1`（联网环境）把它们下载到
> `docs/assets/`，再把对应 `![](https://...)` 改成 `![](assets/<文件名>)` 即可。

> ⚠️ 我在当前沙箱环境里**拉取 Wikimedia 图片被限流（429/400）**，所以未能替你写入本地二进制；
> 但上面脚本里的 URL 是经 Commons API 核实过的准确直链。

## 3. 给仓库的推荐做法（防止外链失效）

1. **改为本地图**：把上面“建议取图”里的图下载到 `docs/assets/`，正文用相对路径引用；
2. **保留源头脚注**：每张图下面注明“来源 + 授权 + 作者”；
3. **可复现**：在 `docs/assets/README.md` 里记录每张图的下载源和授权，方便日后替换；
4. **不复制官方版权图**：UR 官方产品照/手册图**不入库**，需要时用文字链接指过去即可。
