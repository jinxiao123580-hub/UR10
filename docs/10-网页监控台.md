# 10 · 网页监控台

监控台只显示数据，不下发机器人或夹爪运动。当前启动脚本只启动 ATI 原始力、相机（可选）和
网页桥；**不会启动未验证的重力补偿进程**。

```bash
cd ~/UR10
bash scripts/start_dashboard.sh --no-browser
```

浏览器访问 <http://127.0.0.1:8080/>。停止时：

```bash
cd ~/UR10
bash scripts/start_dashboard.sh --stop
```

启动后，力图仅可解释为 `/ft_sensor/wrench_raw` 的原始数据；不把它用于碰撞停止、力控或
抓取判定。ATI 是单消费者，如果无数据，先结束其它 ATI 采集进程。

相机页面可能显示 bgr8 格式，但本机实测三个通道相同，实际为单色。相机采集与点云有效性仍以
[`09-MechEye相机接入清单.md`](09-MechEye相机接入清单.md) 的保存结果为准。
