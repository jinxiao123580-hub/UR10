# A→B→A 观察姿态实验（2026-10-10）

三段均为只读相机/UR 状态采集；B→A 由 `scripts/return_ab_view.py` 按实录路径低速返回，返回离线门禁见 `return-A-gate.json`。棋盘在整个实验中应保持固定。A 原位采集 1 帧，B 和回访 A 各有 31/31 个有效样本；每个样本保存原始图像、点云和 UR 状态。

最初 A 与返回 A 的首 3 帧相比：关节角最大差 0.0057°，控制器 TCP 位置差约 0.038 mm；棋盘 PnP/深度拟合基座位置分别差 0.154/0.137 mm。这个“闭环差”跨越约 24 分钟，**不能**解释成纯机械臂重复定位误差。回访 A 后继续静止的 0.21/0.18 mm 漂移进一步证明，固定报告姿态下仍有时间相关观测变化。

棋盘和背景在两种姿态下同向、同步移动，排除了“只有棋盘角点检测抖动”作为完整解释；但两者仍共用同一相机。PnP 和配准点云也不是独立外部位移测量，不能唯一地区分相机本体/安装件微动与成像链路漂移。B 的漂移较小，但顺序、时间、视角、深度和光照同时变化，不能单独归因为 B 姿态更稳，更不能据此修改 DH 或手眼外参。深度分层分析在 B 只有一个有足够纹理的距离层，在回访 A 的远层只有 3–4 点；视差判别仍不充分。

证据：`A-observation.json`、`B-observation.json`、`A-return-observation.json`（均引用保存的原始图像/点云）；`A-B-A-closure.json`；`B-time-series.json`、`A-return-time-series.json`；`B-background-flow.json`、`A-return-background-flow.json`；`B-A-return-depth-parallax.json`；`B-static-closure.json`、`A-return-static-closure.json`。原始 A→B 手动路径为 `A-to-B.csv`，返回门禁为 `return-A-gate.json`。

下一轮若仍不用外部仪器：在画面内放置**两个固定且不同深度的可跟踪纹理区域**，保持棋盘不动；先预检各深度层至少几十个稳定 RGB+深度对应点，再做静止采集。若要检验姿态依赖，需交替重复 A/B，不能只按一次 A→B→A 的时间顺序推断因果。任何新运动先离线检查并现场确认。
