### 支持、不能排除、已排除的边界

- 支持：角点定位方法会显著改变姿态推断；X 深度姿态不可靠；返回误差含图像与深度共同变化；当前姿态激励不足（平移外参相关矩阵条件数约 1497）。
- 不能排除：内参/成像偏差、深度上游配准或系统偏差、固定件或棋盘变化、时间/运动历史影响、手眼旋转误差、控制器真实运动学误差。没有外部真值，不能把其中某项确定为唯一原因。
- 已排除（限定范围）：输入缺失、旧绝对路径造成无法复算、归档状态均值计算错误、所核对 cloud XYZ→像素的额外缩放/转换错误。固定手眼平移误差不能单独解释这些近纯平移组的毫米级变化；不等于排除所有手眼误差。
