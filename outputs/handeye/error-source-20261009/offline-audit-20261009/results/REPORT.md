## 1. 输入完整性与复算方法

六组共 20 个 accepted 样本：全部 `image.png`、`cloud.npz`、`robot_frames.json`、`sample.json` 均齐全且可解码。原图全部 1280×1024；点云全部 1024×1280×3，有非有限点，但 NPZ 的所有成员均可解压，样本 ID 与数据集一致。9512 帧机器人状态的计数与各 JSON 声明一致，TCP 与关节角数值均有限。每个样本从逐帧 TCP 重算的六维算术均值与归档均值最大差为 0。机器人采样窗口内最大位置偏离均值为 0.04454 mm，最大相对首帧转角为 0.009743°；这些是采样窗口内状态变化，不能代表实体绝对定位精度。算术轴角均值和 SO(3) 均值的最大角差仅 2.77×10⁻⁸°，均值实现不是这里的误差源。

下载的 91 个文件（80 个样本文件及 11 个数据集/配置/源码文件）逐项计算 `SHA1("blob " + 字节数 + NUL + 文件内容)`，全部与指定提交的 Git 树对象一致。详见 `git-blob-verification.json`；SHA256 与大小见 `../download-manifest.json`。点云始终从各 `dataset.json` 同级的 `samples/<sample_id>/cloud.npz` 读取，未使用旧 `/home/jx/UR10/...` 路径。

使用冻结的 `config/handeye_eye_in_hand_20260921.yaml`：`tool0_T_camera` 为该文件的旋转矩阵和平移。文件 SHA256 为 `7fbd513c5f5b3cf2a9014a16ce5fda77543e12c889420abad3ae864e7665f153`；计算前后相同。

主结果的处理链：

1. 从原图重新调用仓库 `detect()` 的 OpenCV 棋盘检测逻辑，全部重新检出 9×6=54 个角点。归档角点仅用于消除棋盘对称的编号翻转，没有用来初始化检测或求解。格长 6 mm，原点为编号第一角点。
2. 使用每帧归档 CameraInfo 的 K 与 D（D 为五个零），独立运行 `SOLVEPNP_ITERATIVE`，重新投影并记录逐角点二维残差。
3. 从逐帧机器人 TCP 重算 A，计算 `C = A · X · B`。组内旋转用 SVD 投影到 SO(3)，平移算术平均。
4. 在每个重检角点周围半径 3 px 的 7×7 点云邻域取有效 XYZ 分量中位数，至少 3 个有效像素才保留该角点；从棋盘物点到这些 XYZ 用带 det=+1 约束的 Kabsch 刚体拟合得到 D，再计算 `C_depth = A · X · D`。拟合没有使用 PnP 的 rvec/tvec。
5. 使用经典 `findChessboardCorners + cornerSubPix` 作检测器对照、IPPE 作平面 PnP 分支对照；检查深度邻域半径 1/2/3/5 px；作 0.05 px 独立像素噪声蒙特卡洛与深度角点 bootstrap。

环境：Python 3.14.6、NumPy 2.5.3、OpenCV 5.0.0（包 5.0.0.93）、SciPy 1.18.1、PyYAML 6.0.3。没有导入/调用 ROS、机器人通讯或运动模块；仅从采集源码 AST 提取 `detect` 数学函数。

## 4. 对误差来源的判别

| 候选原因 | 判定 | 数据依据与限制 |
|---|---|---|
| 视角相关的角点/PnP 系统偏差 | **支持** | 经典检测器的 X 去程板差变为 0.509 mm / 0.0625°，SB 为 1.259 mm / 0.4864°。X 经典重投影均值 0.1756 px，小于 SB 0.3257 px；Y 起点经典 0.1902 px，小于 SB 0.2998 px。仅换同一原图的角点处理便显著改变姿态，证明估计对检测方法敏感。仍没有经典角点的外部真值，不能宣称它准确或已解决全部误差。Y 经典去程仍有 1.483 mm / 0.2108°。 |
| 相机内参、未建模畸变、色图几何/配准 | **不能排除** | 六组 K 相同、D=0。0.05 px 独立像素噪声只产生约 0.047–0.089 mm / 0.027–0.053° 的单帧 PnP 敏感性，明显小于去程姿态变化；系统相关偏差可更大。共同焦距 +1% 将 Y 去程变为 2.086 mm / 0.3130°，径向 k1+0.01 将 X 去程变为 1.105 mm / 0.6177°。这是敏感性示例，不是这些内参真的错了；零 D 可能因为输出已校正，须核对图像管线。 |
| 深度质量及深度/PnP 不一致 | **支持存在限制** | 相机系角点 XYZ 差为 0.64–1.99 mm，不涉及手眼和机器人。它证明两条测量/模型链不一致，不能仅凭差值断定深度有偏而 PnP 正确。X 深度缺失非均匀，内部刚体残差 0.512 mm、组内角度 RMS 0.4725°，需特别降权。 |
| 深度误差作为全部 PnP 异常唯一原因 | **已排除（算法直接因果）** | 本次 PnP 仅用原图、K、D、棋盘格几何，不读深度。深度无法直接制造该 PnP 的角度变化；若色图生成/配准与深度共享上游处理，上游共同误差仍不能排除。 |

| 机械臂实体运动学/绝对定位误差、关节回差、负载挠曲 | **不能排除，尚无独立支持足以定责** | TCP 和 q 都来自控制器，不能互相构成外部真值。返回 TCP 很近说明报告位姿返回较好，不能证明去程实体平移/朝向正确。采集窗口内微动很小，不支持明显运动中采集；静止安装挠曲或模型偏差仍可能。 |
| 本地标称 DH 被软件误用生成这次闭环 | **已排除该实现路径** | 采集器把控制器 TCP 均值直接转矩阵；本次闭环也直接使用归档 TCP，没有调用本地 DH/FK。控制器内部运动学的实体准确度仍未知。 |

## 5. 误差传播与深度可信度

令 `A=(R_A,t_A)`、`X=(R_X,t_X)`、`B=(R_B,t_B)`，板原点为 `p=t_A+R_A t_X+R_A R_X t_B`。手眼平移误差的跨帧贡献为 `(R_A2-R_A1) δt_X`，上界为 `2 sin(Δθ_A/2)||δt_X||`。纯平移时为零。故不能从本实验的平移闭环残差反向估计手眼平移。

固定 R_A 时，手眼旋转误差的平移敏感性约为 `||Δt_B|| δθ_X`；约 0.5° 可以产生毫米级残差，但这是可解释能力，不是外参误差的证据。Y 相机估计平移长度与报告 TCP 长度仅差 +0.0248 mm；X 差 -0.4874 mm。固定旋转保长度，不能在理想纯平移条件下消掉长度差；实际 R_A 小幅变化及相机距离形成的小量需计入，所以该长度差提示尺度/视角/实体运动误差，也不能专门归于 DH。

对朝向，旋转测地距离满足：`d(R_C1,R_C2) ≥ d(R_B1,R_B2) - d(R_A1,R_A2)`，固定 X 的左乘/共轭不会改变角距离。Y 原图 PnP 相机板朝向差 0.39460°，工具差 0.00579°，任何固定手眼旋转下板闭环角差至少 **0.38880°**；X 至少 **0.47369°**（0.48094°−0.00725°）。所以仅重调固定外参无法让这套 SB PnP 数据的板朝向一致。剩余角差必须在相机估计、报告/实体工具姿态不符、安装变化或实体板变化中寻找。

0.05 px 独立零均值像素扰动试验是条件敏感性，不是经标定的置信区间；实际重投影残差可能相关，不能直接当成独立角点噪声。深度 bootstrap 也只评估所见角点内部抽样敏感性，不包含统一深度偏置、图像配准偏置和棋盘形变。两条链共享 K、角点位置与板物点，因此深度对照是不同测量通道，并非完全无共同误差的计量真值。

X 深度尤其不稳：半径 1/2/3/5 px 下，X 去程深度朝向差为 **0.674/0.654/0.431/0.377°**，位置差 0.467/0.468/0.514/0.567 mm；单帧邻域调整引起的朝向变化最高约 **0.851°**。角点 bootstrap 单帧角度 RMS 为 **0.301/0.678/0.718°**。相比之下，Y 去程深度位置在这些邻域下为 1.655–1.675 mm，较稳定，朝向为 0.065–0.106°。X 缺失主要集中在棋盘部分列，虽总覆盖跨度仍为 48×30 mm，却非均匀覆盖；不能把“仍有三十多个点”视为充分条件。

IPPE 的低残差分支与迭代 PnP 接近，另一个分支在这些图上的 RMS 至少 0.9408 px，且姿态差数十度；不支持简单的 180° 编号反转或另一个平面分支被误选为这里约 0.4–0.5° 异常的解释。格点局部化、相机模型和实体板几何的连续偏差仍需检验。

Y 返回板残差约 0.54 mm、X 约 0.16 mm，超过许多组内重复性，但不等于绝对准确度，也不独立证明回差：图像/深度漂移、TCP 实体与报告不符、热/安装变化均可造成。每组仅 3 帧（首组 5 帧），不能把短时 RMS 除以根号样本数后宣称已排除系统误差。

## 7. 下一项最有判别力的实验

**固定机器人与相机，用外部计量的刚性平面棋盘在精密位移台上作板的 A→B→A，复现本次 Y/X 的相对相机视角与图像区域。** 这是建议，未在本次执行。

让棋盘沿与原机器人运动相反的实测向量移动，尽量复现本次的相对距离、视角、图像区域；用量块/位移台和独立 6D 计量确认板的真实平移及转角，棋盘先检查平面度和格长。固定同一 K/D 与色图处理，同时记录 SB、经典角点和深度，增加同位姿重复并交错采集 A/B 以控制时间漂移。精度宜达到 ≤0.05–0.1 mm、≤0.02°，以分辨本次毫米级和约半度的效应。

此时直接比较 `camera_T_board` 与外部测量，不需要手眼和机器人运动学。如果相同图像区域仍出现原有朝向/尺度偏差，便支持相机/角点/板模型；若只深度偏离则支持深度通道/配准；若 SB 与经典分歧重现，优先定位角点局部化；若偏差不重现且外部板计量可信，再进行跟踪实体法兰/相机安装的机器人 A→B→A 计量，以区分运动学与安装挠曲。一次阴性结果也要确认已复现相对成像几何，不能直接宣布相机被排除。
