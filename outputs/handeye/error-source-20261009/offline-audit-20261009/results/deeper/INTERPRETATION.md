# 对现有 20 个样本的进一步误差定位

本轮继续使用已校验的固定提交原图、点云和状态，全程离线。没有增加新实验，没有改写相机内参、棋盘采集参数、手眼 YAML 或 DH。以下数字是诊断结果，不是新的标定参数。

**当前优先排查顺序：图像角点的亚像素定位 → 棋盘格点/局部成像的固定误差图样 → 深度在 X 侧的视角相关失真；剩余位置闭环误差仍混合了外参旋转、相机尺度/位姿偏差和实体运动误差，不能仅凭当前数据认定 DH 错误。**

## 1. 已经定位到角点精化环节，而不只是“两种算法不一样”

对全部 20 张原图，分别执行：原 SB 角点、经典检测后 cornerSubPix（窗口半径 3/5/7/9 px）、原 SB 角点直接 cornerSubPix（窗口半径 7 px）。检测后的物点、PnP、机器人状态、手眼参数全部保持相同。

SB→cornerSubPix7 与 classic→cornerSubPix7 得到的角点最大 RMS 差只有 **0.0000455 px**。也就是说，不需要更换初始检测器，只在 SB 已找到的角点上继续做局部亚像素精化，就会收敛到几乎相同的结果。精化使 SB 原角点移动的单图 RMS 约为数十分之一像素，观察到的各组最大值为 0.407–0.533 px，足以在小棋盘平面 PnP 中改变深度/倾角。

| 处理 | Y 去程板变化 mm / ° | X 去程板变化 mm / ° | X 返回板变化 mm / ° |
|---|---:|---:|---:|
| 原 SB | 1.424 / 0.3955 | 1.259 / 0.4864 | 0.166 / 0.0378 |
| classic + subPix，半径 3 | 0.793 / 0.4196 | 1.874 / 0.1185 | 0.532 / 0.0585 |
| classic + subPix，半径 5 | 1.356 / 0.2233 | 0.596 / 0.0585 | 0.188 / 0.0239 |
| classic + subPix，半径 7 | 1.483 / 0.2108 | 0.509 / 0.0625 | 0.168 / 0.0119 |
| classic + subPix，半径 9 | 1.538 / 0.2142 | 0.526 / 0.0813 | 0.157 / 0.0110 |
| 原 SB + subPix，半径 7 | 1.483 / 0.2108 | 0.509 / 0.0625 | 0.168 / 0.0119 |

半径 5/7/9 的 X 结果形成较稳定范围 0.51–0.60 mm / 0.058–0.081°，而不是只挑到一个碰巧较好的算法参数。半径 3 的结果不稳，在 Y 起点/返回处重投影 RMS 达约 0.68–0.73 px，不能据其较小的某个闭环数值判断它更准确。窗口单位是 OpenCV 半径，完整窗口为 `(2w+1)×(2w+1)`。

重投影均值也支持原 SB 定位需要进一步检查：X B 从 0.3257 px 降到 0.1756 px，X A 从 0.2948 px 降到 0.1827 px。但 Y B 原 SB 为 0.1682 px，精化7后反而为 0.1942 px；所以没有一个处理在每个视角都表现最优，仍不能把精化7当实体真值。棋盘角点覆盖仅约 159–180×108–132 px，平面姿态估计容易受小的局部偏差影响。

在每图依次排除一整行/列角点再解 PnP，SB 的最大朝向变化在 Y 返回/X B/X 返回为约 0.56/0.48/0.50°，精化7为 0.24/0.24/0.23°。Y B 精化后并未更好（约 0.44°，SB 0.30°）。这是棋盘局部数据不完全符合单一理想模型的迹象，不是量化绝对位姿不确定度的置信区间。

**可以说：原 SB 的亚像素角点处理是当前朝向异常的重要贡献项。不能说：加入精化后已得到真实的机械臂或相机精度。**

## 2. 还有与棋盘格点绑定的固定误差图样

先拟合任意平面单应性（8 自由度，不要求其符合已知 K 的刚体位姿），再把各角点偏差映射回棋盘平面坐标。经典精化7的组平均残差图样在六组之间相关系数为 **0.910–0.961**，幅值 RMS 约 **0.052–0.060 mm**。这表明残差明显与棋盘格点编号相关；它可以来自格线印刷/格距非均匀、板的局部几何，或与棋盘局部图案绑定的成像/定位偏差。它不是外部测得的实体板尺寸。

原 SB 的组内图样相关系数约 0.959–0.996，也说明很好的短时重复性可以重复同一系统偏差。简单“黑白格奇偶交替偏差”只能解释 SB 单应性残差能量约 0.3%–2.2%，不足以概括其完整结构；没有把所有问题归于黑白反光。

作了一个固定训练/留出检验：仅用 initial、Y A、Y B 三组学共享格点图样（RMS 0.0540 mm）；用它预测未参与学习的 Y 返回、X B、X 返回。所有处理固定为经典精化7。

| 留出组 | 理想均匀棋盘 PnP RMS px | 加共享图样后 PnP RMS px | 理想棋盘单应性 RMS px | 加图样后单应性 RMS px |
|---|---:|---:|---:|---:|
| Y 返回 | 0.1827 | 0.0892 | 0.1725 | 0.0665 |
| X B | 0.1756 | 0.0925 | 0.1573 | 0.0568 |
| X 返回 | 0.1775 | 0.0893 | 0.1654 | 0.0621 |

它能预测留出图像的残差结构，因此不是只拟合一张图的随机噪声。**但跨视角闭环几乎没有改善**：Y 去程 1.483→1.484 mm / 0.2108→0.2086°，X 去程 0.509→0.510 mm / 0.0625→0.0631°。该图样解释了相当一部分逐角点残差，却没有解释主要的位置闭环偏差。

这项试验只用于归因，不能把图像推出来的格点偏移写成实际板几何或新标定。真实板尺寸与图案相关检测偏差在这里仍有混淆；前三组虽包含不同视角，但独立板计量缺失。

## 3. 深度的内部投影关系正确，实体深度准确性仍未证实

对每个点云从全图每 12 像素抽样有效点，检查 `u=fx·X/Z+cx`、`v=fy·Y/Z+cy`。六组 RMS 均约 **0.000011 px**，仅相当于浮点数舍入；反拟合焦距和主点也与 CameraInfo 一致。

因此，可以排除本次读取时将有组织点云像素索引、相机 XYZ、提供的 K 混用了不同缩放/主点这样的数学转换错误。**这个检查不能证明 K 是实体正确内参，也不能证明深度与色图在相机上游真的正确配准。** 点云的射线关系很可能就是按同一 K 生成的，它与 PnP 因而共享这个几何模型，不能当成独立的内参验证。

另外，绕开稀少的 X 深度角点，从棋盘内缩区域的密集点云拟合平面，再作一次 0.8 mm 残差截断的敏感性检查。以下“平面 RMS”是截断前的数值；法向来自截断后的平面。只评估表面法向，没有借此声称板原点可精确恢复。

| 组 | 内部区域有效深度比例 | 原始平面 RMS mm | 重复平面法向 RMS ° |
|---|---:|---:|---:|
| initial | 99.95% | 0.141 | 0.044 |
| Y A | 99.48% | 0.323 | 0.044 |
| Y B | 100% | 0.198 | 0.007 |
| Y 返回 / X A | 99.52% | 0.322 | 0.061 |
| X B | **58.80%** | **0.665** | 0.056 |
| X 返回 | 99.45% | 0.323 | 0.024 |

密集平面 Y 去程法向变化 0.098°、X 去程 0.534°，返回分别 0.059°、0.047°。X 虽有更多密集点、法向重复性不错，表面残差却更大且缺失不均匀，法向仍不能作为高精度裁决。这恰好演示“稳定的拟合”可以稳定地受偏置影响。棋盘相邻奇偶区域的深度平面偏差中位数差约 0.035–0.151 mm，只能作为图案/深度关联的线索，受区域分布和表面形状影响，不足以定责于黑白反射。

## 4. 剩余位置误差：固定外参旋转仍有解释能力，但不能据此重新标定

在上述精化后的数据中，Y 去程仍约 **1.48 mm**，X 去程仍约 **0.51 mm**。现有数据不支持“处理角点后所有误差都消失”。

做了一项解释能力测试：只允许冻结外参的旋转作同一个小变化，联合拟合 Y、X 两个去程的位置闭环，不拟合外参平移、不修改任何文件。原 SB 数据最优的小转角约 0.603°，剩余 Y/X 位置残差约 0.251/0.592 mm；精化7数据的解释性小转角约 0.544°，剩余约 **0.200/0.261 mm**。

这说明固定外参旋转**可以解释相当部分位置残差**，不能将它排除。它也可以吸收相机位姿偏差或控制器/实体运动差异，因此拟合转角**不等于已测出手眼误差**。只拟合两个去程，没有新的外部真值，也没有把结果作为独立验证；禁止据此直接替换生产标定。

精化后相机估计平移长度与报告 TCP 长度仍分别差约 Y **+0.195 mm**、X **−0.208 mm**。纯旋转保持长度，所以不能把这些剩余数值都当作外参旋转误差；实际微小工具转角的影响也需包含。相机尺度/位姿模型偏差、实体运动与报告位姿差异仍不能分离。

固定手眼平移的抵消与原报告的角距离下界依然成立，但原报告约 0.389°/0.474° 的下界**专属于原 SB 数据**，不能原封不动套给精化后的角点。精化后的观测已改变，这也是当前应优先核对成像估计链的原因。

## 5. 对现有数据可以下到什么程度的结论

| 判断 | 当前依据 |
|---|---|
| 支持：原角点亚像素定位显著影响朝向结论 | 同一 SB 角点经过局部精化即可复现经典检测结果；多个窗口对 X 的改进方向一致。 |
| 支持：存在棋盘格点绑定的非随机残差 | 跨视角图样相关度高，前三组图样可预测后三组；但无法确认它是实体印刷误差还是图案相关定位偏差。 |
| 支持：X 侧深度质量明显下降 | 深度角点 35–36 个，密集区域有效比例仅约 59%，平面残差约 0.665 mm，角点拟合法向对邻域敏感。 |
| 已排除本次计算的若干直接错误 | 文件/单位/均值/PnP 重算正确，点云像素射线与提供的 K 一致；不是旧绝对路径造成，也没有使用本地标称 DH 生成归档 TCP。 |
| 不能排除：固定手眼旋转的部分位置贡献 | 旋转解释测试能降相当多位置残差，但估计链偏差会被它吸收。 |
| 不能排除：相机模型、实体运动学、安装/热漂移 | 未有独立计量；深度与色图又共享提供的射线模型。 |

**现阶段应先将角点精化差异和棋盘固定图样视为已找到的具体问题，再保留剩余闭环位置误差为未分解项。没有证据足以认定 DH 错误或直接改动手眼。**
