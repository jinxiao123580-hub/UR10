# `outputs/` 证据与可复算数据

本目录保存实验运行产生的证据，不是临时缓存。路径被 JSON 计划和复算脚本引用，请勿随意改名。

| 目录 | 内容 |
|---|---|
| `handeye/` | 手眼标定数据集、图像、角点、同步机器人帧、原始点云与求解报告 |
| `vision/` | 物块识别、棋盘预检、悬停/主动视角原始点云、融合与抓放计划 |
| `ft_*`、`gripper/` | ATI 六轴力、夹爪状态和验证证据 |
| `dashboard/` | 运行时日志；不作为版本化实验输入 |

当前视觉自主抓取的验收入口和各文件含义见
[`../docs/17-视觉自主抓取验收.md`](../docs/17-视觉自主抓取验收.md)。
